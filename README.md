# Sonar Rock vs Mine Detection 🔊

Binary classification model to detect whether a sonar signal 
reflects off a rock or a mine.

## Results
| Metric | Score |
|--------|-------|
| Training Accuracy | 83.4% |
| Test Accuracy | 76.2% |
| AUC | 0.74 |
<img width="2383" height="740" alt="sonar_results" src="https://github.com/user-attachments/assets/e62f5268-9d0c-4733-b75a-c4923323eb44" />

## Model
Logistic Regression (sklearn)

## Dataset
UCI Sonar Dataset — 208 samples, 60 features

## Tech Stack
Python, NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
